OceanCore Team Access — সেটআপ

শুধু GitHub-এ upload করলে account creation চালু হবে না। নিচের Supabase সেটআপ একবার করতে হবে।

১. Supabase → আপনার OceanCore project → SQL Editor → New query।
   TEAM-ACCESS-SETUP.sql-এর সম্পূর্ণ লেখা paste করে Run চাপুন।
   আগের SMART-SETUP.sql ইতিমধ্যে চালানো থাকতে হবে। এই নতুন migration-এর পরে পুরোনো SMART-SETUP.sql আবার চালাবেন না।

২. Supabase → Edge Functions → Deploy a new function → Via Editor।
   Function name: manage-team
   Editor-এর index.ts-এ supabase/functions/manage-team/index.ts-এর সম্পূর্ণ code বসিয়ে Deploy function চাপুন।
   Function settings-এ Verify JWT with legacy secret = OFF করুন (যদি ON থাকে)। Function নিজের code দিয়ে user token ও live admin ownership পরীক্ষা করে।
   Supabase CLI ব্যবহার করলে: supabase functions deploy manage-team --project-ref eisxglctozuclrogixka --no-verify-jwt
   Supabase-এর built-in server environment ব্যবহার করে; website-এ কোনো secret/service-role key বসাবেন না।

৩. ZIP Extract করে admin.html, assets folder, supabase folder এবং TEAM-ACCESS-SETUP.sql GitHub repository-এর root-এ upload/replace ও Commit করুন। Folder structure অপরিবর্তিত রাখুন।
   শুধু file upload করলে Supabase function deploy হয় না; ২ নম্বর ধাপ আলাদা করে লাগবে।

৪. GitHub Actions-এর সবুজ tick এলে admin.html খুলে Ctrl+Shift+R দিন। Sign out করে owner account দিয়ে sign in করুন।

৫. Team Access → Email → Password (কমপক্ষে ১২ অক্ষর) → প্রয়োজনীয় access checkbox → Create staff account।
   Staff একই /admin.html ঠিকানায় email/password দিয়ে login করবে। কোনো invitation email পাঠানো হয় না।

৬. Team members-এর Edit access থেকে permission বদলাতে পারবেন। Account enabled-এর tick তুলে Save access দিলে admin features বন্ধ হবে।
   Password বদলাতে Edit access → Password ঘরে নতুন password → Set new password। Access বদলানো ও password বদলানো আলাদা button।

অনুমতি:
Products & Catalogue Import; Categories & Subcategories; Brands; Product Reviews; Enquiries & Follow-up;
Customers/Quotations/Invoices/Delivery; Gallery/Datasheets/Availability; Stock & Suppliers; Bulk Product Edit; Website Content; Website Reports।
Catalogue Import menu-এর জন্য Products, Categories, Brands—তিনটিই নির্বাচন করুন।
Enquiry থেকে quotation করতে Enquiries ও Billing—দুটিই নির্বাচন করুন।
Full administrator নির্বাচন করলে Team Access ও company settings-সহ সব access পাবে। Select all features শুধুমাত্র listed features দেয়।
Access database-এও সীমাবদ্ধ; শুধু menu hide করা হয়নি। Permission পরিবর্তনের পরে staff refresh করলে menu আপডেট হবে।
সবশেষ enabled full administrator-কে disable/demote করা যাবে না।
আগের account ও business records রাখা হয়েছে। Password list-এ দেখানো বা browser storage-এ রাখা হয় না।

যাচাই: ৩০টি database/security check, migration দুইবার চালানো, ১১টি permission আলাদা করে UI startup,
server account create/reset/authorization/rollback, duplicate menu protection এবং পুরোনো quotation save workflow পরীক্ষা পাস করেছে।
Live Supabase-এ এই package deploy করা হয়নি; উপরোক্ত সেটআপ শেষে বাস্তব staff account তৈরি করে পরীক্ষা করুন।
